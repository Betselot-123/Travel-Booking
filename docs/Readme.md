# Tour Booking System

An online platform designed to help customers easily plan and book tours.

## Objectives
- Provide a complete tour planning solution
- Allow customers to customize their trips
- Store and manage booking and customer information
- Improve efficiency through organized scheduling and pricing

## Features
### Customer Features
- Select type of car (SUV, bus, luxury car)
- View tour guide personal information (experience, language, contact)
- Browse places with pictures and descriptions
- View available dates and months
- Choose hotel options
- Fill personal information (full name, ID, phone number)
- Specify number of people (family or individual)
- Receive confirmation with arranged schedule and price

### Admin Features
- Manage tours, locations, and schedules
- Manage vehicles and guides
- Review and approve bookings
- Calculate and send pricing details

## System Components
- **User:** name, national ID, phone number
- **Tour:** location, description, images, available dates
- **Booking:** user details, selected tour, number of people, date
- **Vehicle:** type of car selected
- **Guide:** personal details and experience
- **Hotel:** name, location, price

## Process Flow
1. Customer selects tour preferences
2. Customer fills personal and booking details
3. System processes request
4. Admin arranges schedule, guide, vehicle, and hotel
5. Final details (date and price) are sent to customer
