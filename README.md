# Tour Booking System

An online platform designed to help customers easily plan and book tours.

## Features
- Select destinations, transportation, and hotels
- View tour guides with experience and language details
- Browse places with pictures and descriptions
- 5-step booking wizard with real-time pricing
- Admin dashboard for booking management

## Tech Stack
- **Frontend:** React 18 + TypeScript + Vite
- **Backend:** Express.js + TypeScript + PostgreSQL
- **Patterns:** Strategy, Observer, State Machine, Builder, Facade
